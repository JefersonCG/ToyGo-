# ToyGo-
ToyGo! é um sistema completo de gestão para parquinhos indoor e locação de carrinhos/brinquedos em shopping centers. Combina um executável desktop ultra-robusto e 100% offline com um Sistema Central Web exclusivo para o dono do software.
Com arquitetura de ledger imutável, BI embarcado, design moderno (skins) e modelo de licenciamento flexível (Basic / Premium), o ToyGo! foi projetado para substituir planilhas e PDVs genéricos, trazendo profissionalismo, controle financeiro rigoroso e aumento de receita via venda cruzada e reservas online.
